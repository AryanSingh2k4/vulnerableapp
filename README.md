# NextStore — Modern Retail Web App

A clean, responsive React storefront application designed for modern digital commerce.

## Features

- **Product Catalog**: Curated categories across electronics, lifestyle apparel, and accessories.
- **Dynamic Search & Filtering**: Real-time category selection and multi-attribute search.
- **Interactive Shopping Bag**: Full quantity management, instant item removal, and subtotal calculation.
- **Checkout Modal**: Streamlined payment modal integrated with storefront payment gateway configuration.

## Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
